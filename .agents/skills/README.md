# Skills locaux — e-book d’études et bourses en France

Ces consignes réutilisables sont installées dans `.agents/skills/` pour ce dépôt. Elles sont destinées à guider la préparation de contenu et les contrôles éditoriaux ; ce ne sont pas des logiciels de mise en page ni une preuve que les sources officielles ont été vérifiées.

| Skill | Usage |
|---|---|
| `recherche-bourses-france` | Vérifier les aides d’études : éligibilité, montants, campagne, procédure et sources officielles. |
| `redaction-pedagogique-fr` | Écrire un guide pratique clair en français, sans promesses ni faits inventés. |
| `mise-en-page-ebook` | Définir une mise en page cohérente pour PDF A4, impression et lecture mobile. |
| `controle-qualite-ebook` | Relire le fond, les sources, l’accessibilité, les liens et les exports avant livraison. |

## Portée éditoriale

Dans ce projet, « bourses françaises » est compris comme **bourses et aides financières pour étudier en France**. Le contenu doit rester daté et vérifié auprès des organismes officiels avant toute publication. Les conditions varient selon le programme, le profil et la campagne.

Les skills ne changent pas le statut des contenus existants : le chapitre 1 est un brouillon de travail. Ils ne réalisent pas automatiquement la recherche de sources, l’export PDF ou la validation auprès du public.
