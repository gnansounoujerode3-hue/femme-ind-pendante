## Feuille de preuve à compléter après lecture

- Programme / établissement / niveau / rentrée : …
- Profil concerné (nationalité, résidence, diplôme ; exclusions) : …
- Affirmation à vérifier : …
- Autorité qui décide, URL exacte, rubrique ou page du règlement : …
- Date de **lecture effective** ; date de mise à jour de la source si elle est affichée : …
- Fait constaté, reformulé en une phrase : …
- Qui doit agir ? Pour **quelle** démarche ? Date interne / date du candidat / date du financeur, heure et fuseau si publiés : …
- Argent : monnaie, durée, paiement direct, remboursement, avance et dépenses non couvertes : …
- État de cette campagne : ouvert / clos / ouverture annoncée / **à confirmer**. Justification : …
- Autre notice qui semble contredire la première ; question à poser au service officiel : …
- À reporter dans : fiche / calendrier / sommaire / tableur / texte de vente / autre : …
- Prochaine vérification (notamment avant diffusion) : …

Une ligne sans réponse reste « à confirmer » ou « sans objet » avec la raison, jamais « vérifié » par défaut.
